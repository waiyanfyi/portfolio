# Wai Yan Premium Portfolio

A premium modern portfolio website for Wai Yan (Senior Software Engineer and Business Solutions Consultant), built with React, Vite, Tailwind CSS, and Framer Motion.

## Stack

- React + Vite
- Tailwind CSS v4
- Framer Motion
- React Icons

## Features

- Luxury black-focused glassmorphism design with dark and light mode
- Sticky navbar and smooth section navigation
- Hero intro with typing animation
- About section with animated counters
- Professional timeline and enterprise project showcase
- Project filtering by domain/category
- Skills, services, GitHub statistics, resume download, and contact sections
- Mobile-first responsive layout and scroll-based reveal animations
- SEO-friendly metadata
- GitHub Pages-ready build configuration

## Run Locally

1. Install dependencies

	npm install

2. Start development server

	npm run dev

3. Create production build

	npm run build

## Deploy To GitHub Pages

1. Ensure your repository exists on GitHub.
2. Run deployment command:

	npm run deploy

This publishes the dist output to the gh-pages branch.

## Content Customization

- Update portfolio content in src/data/portfolioData.js
